# lift-analyzer-tool

Python desktop application to analyze lifts on the go.

> [!WARNING]
> This project is just a testbed for us to try things out. Expect rough edges.

## Features

- Pose estimation with MediaPipe
- Joint angle, bar path, and velocity calculations
- Rep counter
- 1RM prediction from warmup sets

## Getting Started

1. (Optional) Create a [virtual environment](https://docs.python.org/3/tutorial/venv.html) so dependencies stay isolated.
2. Install the dependencies:

```bash
   pip install -r requirements.txt
```

3. Run the app:

```bash
   python main.py
```
